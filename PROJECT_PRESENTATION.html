Enterprise Integrity

4-Layer Security & Fallback Resilience

🛡️ 1. SENSITIVE_DATA_GUARD

Filters confidential engineering data and screens for prompt injection attacks before reaching LLM layers.

⚡ 2. AST Python Repr Extractor

Strips raw Python list/dict string representations (`[{'type': 'text'}]`) into clean markdown text automatically.

🔍 3. Sequence Diagram <br/> Filter

Removes invalid HTML linebreaks inside participant names to prevent Mermaid sequence diagram syntax errors.

🧱 4. Syntax Error Boundary

Catches rendering exceptions gracefully, preventing UI crashes and maintaining 99.9% application availability.
